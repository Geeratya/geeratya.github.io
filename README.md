# geeratya.github.io

Landing page for [Geeratya](https://github.com/Aleksanderis/Geeratya), a keyboard-first terminal client for Jira Cloud. Static files, no build step: `index.html`, `assets/`, `media/`, `robots.txt`, `sitemap.xml`.

Preview: `python3 -m http.server 8000` and open http://localhost:8000.

The Features list is a copy of the one in the main README; update both. `media/demo.gif` and `media/demo.webm` are recorded in the main repository with `scripts/demo.sh`; the main README links them from this site.
